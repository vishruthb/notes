# Theory  
Haskell = $\lambda$‑calculus + syntax + static polymorphic types + laziness.
- **Purely functional** – every expression is referentially transparent.  
- **Lazy evaluation** – compute values *only when needed*. Enables infinite data like `[1..]`.  
- **Static typing with inference** – the compiler deduces principal types.  
- **First‑class functions** – pass/return functions freely.
