1. [[💧 Breadth First Search|💧 breadth first search]] explores a graph level by level, ideal for finding shortest paths in unweighted graphs.
2. [[🚟 Depth First Search|🚟 depth first search]] dives deep along one branch before backtracking, useful for connectivity and topological sort.
3. [[🗺️ Dijkstra|🗺️ dijkstra]] finds shortest paths from a source in a non-negative weighted graph using a priority queue.
4. [[🚢 Prim's and Kruskal's Algorithm|🚢 prim's and kruskal's algorithm]] greedily builds a minimum spanning tree by selecting the lightest edges without creating cycles.
5. [[🥽 Union-Find|🥽 union-find]] manages disjoint sets with near‑constant time union and find operations (useful for connectivity).
6. [[📍 Hashmap|📍 hashmap]]s store key–value pairs for average $O(1)$ lookup, insertion, and deletion.
7. [[🍽️ Stacks|🍽️ stacks]] provide a lifo structure supporting push and pop at one end, handy for backtracking and parsing.
8. [[🏁 Queues|🏁 queues]] provide a fifo structure supporting enqueue at rear and dequeue from front, ideal for bfs.
9. [[⛓️ Linked List|⛓️ linked list]]s provide a sequence of nodes where each node points to the next, allowing $O(1)$ insertion/deletion with a pointer.
10. [[📊 Graphs|📊 graphs]] model entities (nodes) and their relationships (edges), foundational for network and connectivity problems.
11. [[🌳 Binary Search Tree|🌳 binary search tree]]s are binary trees where left child < node < right child, giving $O(\log n)$ search on average.
12. [[⛰️ Heaps|⛰️ heaps]] are a tree‑based priority queue that lets us extract the max (or min) in $O(\log n)$.
13. [[📐 K-Dimensional Tree|📐 k-dimensional tree]]s partition k‑dimensional points recursively, useful for nearest neighbor searches.
14. [[📂 B-Trees and B+ Trees|📂 b-trees and b+ trees]] provide wide, multi‑way trees optimized for disk and block storage, minimizing i/o operations.
